# 依頼

`cart.py` はショッピングカートと注文計算のモジュールです。本番で複数の不具合報告が来ています。

このモジュールに潜んでいるバグを**すべて**見つけてください。コードの修正は不要です(調査のみ)。

成果物は2つ、同じディレクトリに保存してください:

1. **`findings.json`** — 発見したバグの機械可読リスト。次の形式:
   ```json
   [
     {"line": 34, "bug": "一言でバグの内容"},
     {"line": 86, "bug": "..."}
   ]
   ```
   `line` は該当バグの行番号(最も関係の深い1行)。
2. **`REPORT.md`** — 依頼主向けの説明。各バグの発生条件・症状・修正案を含める。

各バグは実際に再現させて確認すること。推測でバグと決めつけないこと。
