# 依頼

このリポジトリは日次レポート生成ツールです。運用引き継ぎのため、コードを調査して以下の質問に答えてください。それぞれ根拠となる箇所(ファイルと行)も示してください。

1. 設定値はどこから読まれ、複数の場所で同じキーが設定されている場合の優先順位はどうなっていますか?
2. 環境変数 `RPT_TIMEOUT` に `abc` を設定して起動すると何が起きますか?
3. データ取得時にタイムアウト(`TimeoutError`)が発生した場合、リトライされますか?
4. リトライされる場合、リトライの間隔はどう決まりますか?
5. 設定ファイル `report.json` が存在しない場合、起動はどうなりますか?
6. 設定ファイルで `locale` を `"ja"` にし、環境変数 `RPT_LOCALE` を空文字列に設定した場合、レポートのロケールは最終的に何になりますか?
