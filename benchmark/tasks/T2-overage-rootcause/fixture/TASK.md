# 依頼

このリポジトリは従量課金の請求判定です。`python3 -m pytest test_billing.py` を実行すると `test_exact_limit_is_not_overage` が落ちます。

顧客がちょうど上限ぴったりの使用量なのに「超過課金対象」と誤判定される、という報告が来ています。原因を調査して**根本から**修正してください。修正後、なぜこの問題が起きていたのか(根本原因)も報告してください。

制約: `test_billing.py` は変更しないこと。上限判定の意味(「ちょうど上限は超過ではない」「上限を1でも超えたら超過」)は仕様として維持すること。
