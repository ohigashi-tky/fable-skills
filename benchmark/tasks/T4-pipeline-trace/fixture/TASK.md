# 依頼

このリポジトリはハンドラのレジストリ、リトライ、キャッシュ、設定解決からなる小さなパイプライン基盤です。運用引き継ぎのため、コードを調査して以下の質問に答えてください。

各質問の答えは短い値です。成果物は2つ、同じディレクトリに保存してください:

1. **`answers.json`** — 次の形式:
   ```json
   {"q1": "...", "q2": "...", "q3": "...", "q4": "...", "q5": "...", "q6": "...", "q7": "...", "q8": "..."}
   ```
2. **`REPORT.md`** — 各回答の根拠(ファイル:行)を含む説明。

## 質問

1. `get_handler("normalize")("  Hi ")` は何を返すか(文字列そのもの)。
2. `compute(5)` は何を返すか。
3. `retry(times=2)` でラップされた関数は、1回の呼び出しで最大何回 `fn` を実行するか(数値)。
4. 「4回目の実行で初めて成功する」関数を `retry(times=2)` でラップして呼ぶと、成功して値を返すか、それとも例外になるか。
5. `retry` がデフォルトで再試行の対象とする例外は何か。`TypeError` は再試行されるか。
6. 環境変数 `APP_MODE` を空文字列 `""` に設定したとき、`resolve("mode")` は何を返すか。
7. 環境変数 `APP_WORKERS="8"` のとき、`resolve("workers")` が返す値とその型は何か。
8. `memoize` は関数が投げた例外をキャッシュするか(する/しない)。

挙動が自明でないものは実際にコードを実行して確認すること。
